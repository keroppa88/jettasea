# Zorn Sea

Zorn の絵に着想を得た、Three.js の航行できる海です。水面と空、波による船の揺れ、速度で変わる船首の泡と船尾の航跡をシェーダー等で表現します。参考画像をテクスチャとして貼ってはいません。

## 操作

- W / ↑：スロットルを上げる。S / ↓：下げる（速度は設定値へ徐々に変化）
- A / ←、D / →：舵を切る。画面上の左右ボタンも使用可能
- スロットルのスライダー：速度を設定
- 水面をドラッグ：視点を回す。ホイール／ピンチ：拡大縮小
- 「船尾から見る」：追跡視点へ戻る
- 色調：青い夕景／港の薄明／群青の嵐／茜の夕映え。空・雲・海・反射・船の光が連動

海面のメッシュは船と一緒に移動し、波は世界座標で計算するため、航行中に模様が船に固定されません。遠くの水面は空の地平線へ溶け込みます。船は独立した `boat.js` の簡易モデルで、後で VOX モデルに置き換える前提です。

雲は `car2026/js/main.js` の雲ドームを参照し、2種類の設定（広い雲と横に伸びる雲）を `clouds.js` に分離して採用しています。雲の投影は方向ベクトルを使うため、360度回しても縦の継ぎ目が出ません。

静的なページです。`python3 -m http.server 8000` などでローカル起動できます。Three.js はバージョン固定で jsDelivr から読み込み、GitHub Pages は `main` ブランチのルートから公開します。
