# Zorn Water Study

Anders Leonard Zorn の絵に着想を得た、Three.js の3D水面スケッチです。水面の形状と法線、波筋の明暗、反射の短い白い光をシェーダーで計算しています。参考画像自体はページに使用していません。

## 操作

- ドラッグ：視点を回す（水面すれすれまで）
- ホイール／ピンチ：近づく・遠ざかる
- 青い夕景／港の薄明：水面の色調変更
- 波を止める／視点を戻す

`index.html` を静的サーバーで開けば動作します。例えば `python3 -m http.server 8000` を実行して `http://localhost:8000/` にアクセスしてください。Three.js はバージョンを固定して jsDelivr から読み込みます。GitHub Pages ではブランチ `main` のルートを公開元に指定してください。
